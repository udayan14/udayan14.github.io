# udayan14.github.io

Personal website and portfolio of **Udayan Joshi** — [https://udayan14.github.io](https://udayan14.github.io)

## Structure

- `index.html` — Main portfolio (Experience, Granted U.S. Patents & Applications, Publications & Projects, Education, Technical Stack)
- `cv/index.html` — Dedicated print-friendly Curriculum Vitae (`/cv/`)
- `assets/css/style.css` — Responsive light/dark design system and print stylesheet
- `assets/js/main.js` — Theme switcher, patent status/keyword filter, copy-email helper, and scroll-spy navigation
- `.nojekyll` — Direct static serving on GitHub Pages with zero Ruby/Jekyll build dependencies

## Local Preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
